🔌 Wejście w tryb Maskrom

Tryb Maskrom to specjalny tryb programowania procesora RK3326. Konsola musi być w tym trybie aby można było wgrać oprogramowanie.

A

Metoda 1 — Przycisk POWER (zalecana)

⚠️ Metoda dla zaawansowanych użytkowników. Wymaga otwarcia konsoli!
  1. Upewnij się że bateria jest naładowana powyżej 15%
  2. Wyłącz konsolę (jeśli jest włączona)
  3. Podłącz kabel USB do portu USB-2 konsoli i do komputera
  4. Zewrzyj testpointy TP1 → GND metalową pensetą lub kabelkiem ( 2 = TP1 , 4 = GND)
  5. Naciśnij i przytrzymaj przycisk POWER
  6. Sprawdź na komputerze czy konsola jest wykryta
B

Metoda 2 — Zwarcie testpointów TP1 do GND BEZ PODŁĄCZONEJ BATERII

⚠️ Metoda dla zaawansowanych użytkowników. Wymaga otwarcia konsoli!
  1. Otwórz obudowę konsoli
  2. Podłącz kabel USB do portu USB-2 konsoli (zasilanie) a następnie do swojego Komputera
  3. Zewrzyj testpointy TP1 → GND metalową pensetą lub kabelkiem ( 2 = TP1 , 4 = GND)
  4. Podłącz kabel USB do portu USB-3 konsoli (zasilanie) [cały czas trzymając TP1 zwarty go GND]
  5. Usuń zwarcie po wykryciu przez komputer
✓

Weryfikacja połączenia (Linux)

lsusb | grep 2207
Powinieneś zobaczyć coś podobnego do:
Bus 00X Device 00X: ID 2207:330d Fuzhou Rockchip Electronics Company

Weryfikacja połączenia (Windows)

Otwórz Menedżer urządzeń → szukaj Rockchip USB Device lub urządzenia z ID 2207:330d.

🔌 Entering Maskrom Mode

Maskrom is a special programming mode of the RK3326 processor. The console must be in this mode before firmware can be flashed.

A

Method 1 — POWER button (recommended)

⚠️ For advanced users only. Requires opening the console!
  1. Make sure the battery is charged above 15%
  2. Turn off the console (if it's on)
  3. Connect USB cable to USB-2 port of console and to computer
  4. Short testpoints TP1 → GND with a metal pin or wire ( 2 = TP1 , 4 = GND)
  5. Press and hold the POWER button for about 3-6s
  6. Check on your computer if the console is detected
B

Method 2 — Short testpoints TP1 to GND WITHOUT BATTERY CONNECTED

⚠️ For advanced users only. Requires opening the console!
  1. Open the console case
  2. Connect USB cable to USB-2 port and then to your PC
  3. Short testpoints TP1 → GND with a metal pin or wire ( 2 = TP1 , 4 = GND)
  4. Connect USB cable to USB-3 port of console (power) [still TP1 shorted to GND]
  5. Remove the short after detection by the computer
✓

Verify connection (Linux)

lsusb | grep 2207
You should see something like:
Bus 00X Device 00X: ID 2207:330d Fuzhou Rockchip Electronics Company

Verify connection (Windows)

Open Device Manager → look for Rockchip USB Device or device with ID 2207:330d.

Postępuj zgodnie z instrukcjami na ekranie

  2. Skrypt sprawdzi czy konsola jest wykryta w trybie Maskrom
  3. Potwierdź że konsola jest widoczna (t/y)
  4. Zdecyduj czy wyczyścić pamięć przed wgraniem (opcjonalne)

Run the flash script

bash ~/flash_gamemt.sh

Follow on-screen instructions

  1. Choose language (1 = Polish, 2 = English)
  2. The script will check if the console is detected in Maskrom mode
  3. Confirm the console is visible (y)
  4. Decide whether to erase memory before flashing (optional)
  5. Wait for completion — this may take several minutes

Uruchom rkflashtoolv3

Otwórz folder z rozpakowanym firmware i uruchom rkflashtoolv3.exe jako administrator.

2

Wybierz wszystkie pliki obrazów

W programie zaznacz wszystkie pliki z rozszerzeniem .img znajdujące się w folderze Image_hendheld_e6_gamemt:

  • boot.img
  • system.img
  • recovery.img
  • misc.img
  • parameter.txt (lub plik konfiguracyjny)

3

Rozpocznij flashowanie

Kliknij przycisk Start lub Flash i czekaj na zakończenie procesu. Nie odłączaj kabla USB ani nie wyłączaj komputera.

Proces może potrwać kilka minut — na ekranie pojawi się pasek postępu.
4

Zakończenie

Po wyświetleniu komunikatu o sukcesie możesz odłączyć kabel USB od konsoli.

✅ Flashowanie zakończone! Konsola jest gotowa do pierwszego uruchomienia.
1

Run rkflashtoolv3

Open the folder with extracted firmware and run rkflashtoolv3.exe as administrator.

2

Select all image files

In the program, select all .img files located in the Image_hendheld_e6_gamemt folder:

  • boot.img
  • system.img
  • recovery.img
  • misc.img
  • parameter.txt (or config file)
  • and any other .img files if present
Make sure the console is connected in Maskrom mode (should be visible in the program).
3

Start flashing

Click Start or Flash and wait for the process to complete. Do not disconnect the USB cable or turn off the computer.

The process may take several minutes — a progress bar will appear on screen.
4

Completion

After a success message appears, you can disconnect the USB cable from the console.

✅ Flashing complete! The console is ready for first boot.

💾 Przywracanie oryginalnego oprogramowania (backup)

W folderze Image_hendheld_e6_gamemt\old_backup_orginal_firmware znajduje się oryginalne oprogramowanie producenta.

Jeśli coś poszło nie tak, lub chcesz wrócić do fabrycznego systemu, możesz przywrócić oryginalne firmware dokładnie tą samą metodą, jaką wgrywałeś niestandardowe oprogramowanie — wystarczy użyć plików z folderu old_backup_orginal_firmware zamiast domyślnych obrazów.

1

Krok 1 — Przygotowanie plików

Skopiuj zawartość folderu old_backup_orginal_firmware do głównego folderu Image_hendheld_e6_gamemt (nadpisując pliki) lub wskaż w narzędziu flashującym bezpośrednio ścieżkę do tego folderu.

2

Krok 2 — Wejście w tryb Maskrom

Postępuj zgodnie z instrukcją wejścia w tryb Maskrom (opisana powyżej).

3

Krok 3 — Flashowanie oryginalnego firmware

Użyj tej samej metody co przy instalacji niestandardowego oprogramowania:

  • Linux: uruchom bash ~/flash_gamemt.sh
  • Windows: użyj rkflashtoolv3.exe i wybierz pliki z folderu backup
✅ Po zakończeniu konsola wróci do stanu fabrycznego — wszystkie zmiany zostaną cofnięte.

💾 Restoring original firmware (backup)

The folder Image_hendheld_e6_gamemt\old_backup_orginal_firmware contains the original manufacturer firmware.

If something went wrong, or you want to return to the factory system, you can restore the original firmware using exactly the same method as for custom firmware — just use the files from the old_backup_orginal_firmware folder instead of the default images.

1

Step 1 — Prepare files

Copy the contents of old_backup_orginal_firmware to the main Image_hendheld_e6_gamemt folder (overwriting files) or point your flashing tool directly to that folder.

2

Step 2 — Enter Maskrom mode

Follow the Maskrom entry instructions described above.

3

Step 3 — Flash original firmware

Use the same method as for installing custom firmware:

  • Linux: run bash ~/flash_gamemt.sh
  • Windows: use rkflashtoolv3.exe and select files from the backup folder
✅ After completion, the console will return to factory state — all changes will be reverted.
